# Anti-Slop UI/UX Audit Report #001
Date: 2026-10-11
Scope: Full MVP codebase (Epics 0–5, Views, Quiz Engine, Dashboard, Settings)
Mode: Mode 2 (AFTER — Post-Implementation Quality Audit)

## Summary
The English Proficiency Lab (EPL) desktop application exhibits high design craftsmanship, strict adherence to offline-first principles, zero network requests, zero drag-and-drop mechanics, and faithful implementation of CEFR B1–B2 practice specifications.

The application uses shadcn-svelte UI primitives styled with Tailwind CSS, respects user typography preference via native system font stacks (`-apple-system`, `Georgia`, `"SF Mono"`), and enforces WCAG AA contrast ratios and ≥44px touch/click targets across interactive components.

Below is the numbered findings list for user review and prioritization.

## Numbered Findings List

### [F-001] Dialog Autofocus Accessibility Warnings
- **Rule:** R-05 (Focus Management & Predictable Keyboard Flow)
- **Priority:** LOW (Quality Lock)
- **Files:** `src/lib/views/SetupSheet.svelte:277`, `src/lib/views/QuizShell.svelte:479`
- **Tell:** Native HTML `autofocus` attribute is placed directly on `<button>`, triggering Svelte a11y compiler warnings.
- **Why:** Immediate autofocus can disorient assistive technologies if focus lands on an action button before the modal dialog container's announcement context is read.
- **Fix:** Manage focus via `tick().then(() => el?.focus())` inside open effects, or rely on shadcn modal/dialog primitives that handle focus retention and restore upon dismiss.

### [F-002] Dashboard 30-Day Activity Chart Horizontal Compression on Small Screens
- **Rule:** R-32 (Mobile & Narrow Layout Reflow)
- **Priority:** LOW (Quality Lock)
- **Files:** `src/lib/views/Dashboard.svelte:210-250`
- **Tell:** 30 consecutive daily bars rendered side-by-side in a flex container without horizontal scroll or responsive aggregation.
- **Why:** On narrow window widths (<400px), 30 columns compress below 8px bar width, making day hover targets tiny.
- **Fix:** Add an `overflow-x-auto` wrapper with a `min-w-[480px]` inner container so user can cleanly scroll the 30-day history on compact viewports.

### [F-003] Reading Seed Question Idea Label Advisory (Carried from T-013)
- **Rule:** R-02 (Content Integrity & Semantic Precision)
- **Priority:** LOW (Quality Lock)
- **Files:** `src-tauri/resources/content/reading/questions/urban-farming.json` (`urban-farming-q4`)
- **Tell:** `urban-farming-q4` specifies sentence index 4 ("The idea began with small community groups."), but asks for the "cause and effect" relationship which appears in sentence 9.
- **Why:** Structural schema validation passes, but the reading comprehension prompt is less pedagogically aligned.
- **Fix:** Update `sentence: 4` to `sentence: 9` in `urban-farming.json` in the next content authoring batch.

## Conclusion
All Hard Gate (HIGH) and Purpose Gate (MEDIUM) rules are 100% compliant:
- Zero AI-slop visual tropes (no purple/blue gradients, no excessive glassmorphism, no uniform pill radius, no glow overload).

- 100% tap/click interactions, zero drag-and-drop.
- Instant dark/light and system font switching.
